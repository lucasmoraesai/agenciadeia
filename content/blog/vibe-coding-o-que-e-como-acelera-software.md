Vibe coding é o nome que ganhou o desenvolvimento de software assistido por IA. Em vez de escrever cada linha à mão, você descreve o que quer e a IA gera o código — com revisão humana por cima.

O resultado: sistemas que levavam meses saem em dias.

## Como o vibe coding funciona

1. **Você descreve** a funcionalidade em linguagem natural.
2. **A IA gera** o código.
3. **Você testa** e aponta ajustes.
4. **A IA corrige** em segundos.
5. **Revisão humana** garante qualidade.

É um ciclo rápido de "descrever, gerar, testar, ajustar" — muito mais veloz que o desenvolvimento tradicional.

## O que dá para construir com vibe coding

- **Aplicações web** completas.
- **Landing pages** de alta conversão.
- **Integrações** entre sistemas.
- **Dashboards** com dados em tempo real.
- **MVPs** para validar ideias antes de investir pesado.

## Os limites do vibe coding

Vibe coding não é mágica. Ele funciona bem quando:

- O escopo é bem definido.
- Há revisão humana especializada.
- O código é testado de verdade.

Sem revisão, o risco é gerar código bonito mas quebrado. Por isso, a combinação ideal é **IA para velocidade + humano para qualidade**.

## Por que isso muda o custo do software

O custo de um projeto de software é dominado por **horas de desenvolvimento**. Se a IA reduz essas horas em 80%, o custo cai na mesma proporção.

É por isso que o modelo de assinatura com vibe coding entrega software "de graça": o custo de gerar código com IA é baixo, então o desenvolvimento vira mais uma entrega dentro da assinatura.

## Como começar

1. **Defina o problema** que o software resolve.
2. **Escreva o escopo** em uma página.
3. **Comece por um MVP** — a versão mínima que já gera valor.
4. **Valide com usuários** antes de expandir.

O erro clássico é querer construir tudo de uma vez. Com vibe coding, o caminho é o oposto: construa pequeno, valide rápido, expanda o que funcionou.
